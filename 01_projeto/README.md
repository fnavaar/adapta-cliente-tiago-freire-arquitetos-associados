# 01_projeto — o que estamos construindo e por quê

- `objetivo.md` — o objetivo do projeto em linguagem de negócio: o que a empresa vai conseguir
  fazer ao fim que não consegue hoje, com a métrica de sucesso. Inclui o **fora de escopo**
  (o que este projeto não faz — protege o prazo de 4 meses).
- `visao-do-projeto.md` — o arco completo das 5 fases, uma linha por fase, e o porquê do
  projeto. O detalhe de cada fase chega quando ela abre.
- `constituicao.md` — as regras estáveis do projeto: papéis, stack permitida, o que o champion
  pode tocar, a linha vermelha e o formato da dívida deliberada. Só muda por emenda registrada.

> Preenchido pela consultoria na criação do repositório. Se algo aqui parecer errado ou
> desatualizado, registre no `changelog.md` como DÚVIDA — não edite diretamente.
