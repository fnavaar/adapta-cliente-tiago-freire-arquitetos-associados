# 03_documentos — materiais do projeto

Dois tipos de conteúdo:

1. **Documentos da empresa** usados no projeto (planilhas, políticas, modelos) — adicione aqui
   o que a consultoria pedir, e registre no `changelog.md`.
2. **Materiais entregues pela consultoria** — guias, prompts, treinamentos e os extras
   desbloqueados ao longo das fases.

> Não suba senhas ou credenciais. Se uma task pedir um acesso, combine a entrega direto com o
> consultor.
