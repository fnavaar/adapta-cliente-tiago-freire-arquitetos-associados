# 06_notas — memória do projeto (sua)

Notas, aprendizados e observações do champion durante a execução — em `.md`, uma nota por
arquivo, nome livre. O consultor lê tudo aqui na sincronização; o que virar padrão alimenta o
acompanhamento do projeto.

- `debug/` — relatórios de debug (`debug-AAAA-MM-DD-<slug>.md`) salvos por
  `/adapta-cliente:destravar-task` quando o problema rendeu aprendizado, ficou bloqueado ou
  gerou DÚVIDA para o consultor.

Esta pasta é do projeto e fica com o cliente — é a memória do **seu** projeto (D18). Ideia fora
da fase atual é bem-vinda aqui: vira sinal para o consultor avaliar, não implementação por conta
própria.
