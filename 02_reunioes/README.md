# 02_reunioes — atas das reuniões do projeto

Uma pasta por reunião: `NN. <data>: <assunto>/` com a ata e as decisões.

- As reuniões de fechamento de fase acontecem a cada ~20 dias: mostram o que ficou pronto,
  validam contra o critério de pronto e abrem a próxima fase.
- Decisões tomadas em reunião que mudam o trabalho também aparecem no `changelog.md`.
